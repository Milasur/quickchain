# Buzón del equipo

Para pedirle algo a otra persona (o a su agente) sin perderlo en el chat.

## Protocolo
- Un archivo por pedido: `buzon/NNN-de-a-asunto.md` (ej. `001-josue-juliana-id-contrato.md`). `NNN` es el siguiente número libre.
- Contenido obligatorio:
```md
# Asunto
- **De:** nombre
- **Para:** nombre
- **Qué:** lo que se necesita
- **Para cuándo:** fecha y hora (CR)
- **Criterio de listo:** cómo sabemos que está hecho
- **Estado:** abierto | en curso | listo
```
- Quien recibe cambia el **Estado** y agrega una línea de respuesta abajo. No se borran pedidos.
- Nada de secretos en el buzón.
